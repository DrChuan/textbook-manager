# 高中数学教材笔记本

本仓库包含“高中数学教材笔记本”的桌面端源码：以教材小节为单位整理引言、知识点、题型、例题、问题串、易错辨析、其他版本参考和课后备注，并支持 LaTeX、教材 PDF 引用、截图和坚果云文件夹同步。

## 启动

安装 Python 依赖与 KaTeX：

```bash
pip install PySide6 pypdf
npm install
```

然后运行：

```bash
python 教学设计工作台/教学设计工作台.py
```

## 本机教材资料

教材 PDF、节引言资料包、笔记 JSON 和截图均不包含在本仓库中，避免公开个人学习资料及受版权保护的教材内容。

首次启动后，请在本机配置教材 PDF 目录；程序会按需要提示选择。若要使用完整目录与节引言，需要另行准备资料包，并将其放到项目根目录的 `节引言资料包/` 或应用可识别的本机资料路径。

人教 A 版和苏教版是可写笔记的主教材。右侧阅读器还可按书签参考北师大、鄂教、沪教、人教 B、湘教版：PDF 路径只保存在本机；“其他版本参考”条目、截图和人教 A / 苏教版之间已确认的小节共享关系会随同步资料夹保存。

## 隐私与同步

通过“同步设置”选择坚果云同步文件夹后，笔记 JSON、截图和锁文件会保存在该文件夹中。请勿将其中的个人数据直接提交到公开仓库。
