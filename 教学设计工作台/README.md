# 高中数学教材笔记本

这是一个本地教材研读与备课笔记工具。它读取人教 A 版和苏教版的教材目录、节引言，并按每个小节沉淀可持续使用的教学与解题资料。

## 启动

在本目录运行：

```bash
conda run -n base python 教学设计工作台.py
```

## 笔记结构

- 教材引言（只读）与一段引入备注
- 知识点列表：标题 + 自由内容
- 基本例习题类型：题型名称 + 示例 + 备注
- 有价值的例习题：标题 + 来源 + 原题 + 备注
- 问题串设计：大问题下可继续添加、重排追问
- 易错与辨析：标题 + 内容
- 课后备注：只记录本节调整点或待补材料

知识点、题型、例题、问题串与易错辨析均由可新增、删除、拖拽排序的独立项目组成。顶部锚点可快速跳至指定栏目，非当前栏目会收起，减少长页面干扰。

所有可编辑文本字段都支持文字和 LaTeX。将公式放在**单个**美元符号之间，例如 `$f(x)=x^2+1$`。字段平时只显示排版结果；点击字段后显示完整源码，点击“完成编辑”后输入控件会收起并重新渲染。

笔记数据保存为同目录中的“我的教材笔记.json”。旧版教学卡和早期通用项目卡都会在首次读取时迁移到新版结构，原文本不会被丢弃；建议定期从“文件”菜单导出备份。
